# 01. 도메인 지식 — SK㈜ 지주사 NAV 와 할인율

> 본 문서는 4 개 에이전트(Hypothesis/Collector/Analyzer/Verifier)가 공통으로 참조합니다.
> 모든 에이전트는 새 작업을 시작하기 전 본 문서 §1~§4 만큼은 반드시 숙지해야 합니다.

## 1. SK㈜ 의 정체

SK㈜는 SK 그룹의 사실상 지주회사이며, 사업회사라기보다 **자회사 지분과 자체 사업(IT 서비스, 신성장 투자)** 의 혼합체입니다.

### 1-1. 주요 보유 지분 (2025년 기준 대략, 정확한 수치는 분기 공시로 확인)
| 자회사 | 지분율 | 사업 |
|---|---|---|
| SK이노베이션 | ~33% | 정유·배터리·E&S 통합 |
| SK텔레콤 | ~30% | 통신·AI |
| SK스퀘어 | ~30% | 반도체 투자(SK하이닉스 간접) |
| SK하이닉스 | (SK스퀘어 통한 간접) | 메모리 반도체 |
| SK에너지·SKC·SK네트웍스 등 | 30~50% | 화학·소재·물류 |
| SK바이오팜 | ~64% | 바이오 |
| SK시그넷·SK실트론 등 비상장 | 다수 | — |

### 1-2. 자체 사업
- **SK C&C** (구 SK주식회사): IT 서비스, 시스템 통합
- **신성장 투자**: 수소, AI 데이터센터, 친환경 에너지 직접 투자
- **자사주**: 매년 일정 비율 보유·소각 정책 변동

> 분석에서 자체 사업 가치는 보통 별도로 평가하거나, 단순화를 위해 평균 P/E 적용.

## 2. NAV 계산식

```
NAV = Σ (보유 지분율 × 자회사 시가총액)        # 상장사
    + Σ (보유 지분율 × 비상장사 추정 가치)      # 비상장
    + 자체 사업 추정 가치                        # SK C&C, 투자
    + 순현금                                     # 현금 - 부채
    - 비지배지분 보정                            # 필요 시
```

NAV 할인율:
```
할인율 = (NAV - 시가총액) / NAV × 100%
```

### 2-1. 비상장 가치 추정 보수 원칙
- DCF 또는 동종업계 멀티플 (P/E, EV/EBITDA) — 분석 일관성 위해 **방법론은 한 번 정하면 시계열 내내 유지**
- 다음 가설 검증 시: 비상장 가치 가정 변경 시 결과가 어떻게 달라지는지 sensitivity 필수

### 2-2. 통상 한국 지주사 NAV 할인율 분포
- 평균: 약 50~60% (글로벌 평균 25~35% 대비 매우 높음)
- SK: 30~55% 사이 변동 (시기별 상이)
- 삼성물산, LG, GS, 한화 등이 비교 대상 — but 각자 사업 구조가 달라 직접 비교는 신중

## 3. 왜 한국 지주사 NAV 할인율이 큰가 — 메커니즘

본 시스템이 발굴할 가설들의 **출발점**이 되는 통상적 설명들:

| 메커니즘 | 설명 | 측정 가능한 변수 후보 |
|---|---|---|
| 거버넌스 디스카운트 | 소액주주 보호 약함, 일감몰아주기 우려 | 사외이사 비율, 주주환원율, 이사회 독립성 점수, KCGS 등급 |
| 이중과세 | 자회사 배당이 지주사로 올 때 한 번 더 과세 | 효과적 세율, 배당 leakage |
| 상속 risk | 오너 일가의 상속·경영권 승계 이슈 | 오너 지분 변동, 상속 관련 공시 |
| 자산 매각 어려움 | 비상장 자산 유동화 어려움, 디스카운트 거래 | 비상장 자산 비중, 매각 이력 |
| 포트폴리오 디스카운트 | 다각화로 인한 기업 가치 합 < 부분의 합 | conglomerate count, 사업 부문 수 |
| 정보 비대칭 | 자회사 가치를 시장이 정확히 모름 | 애널리스트 커버리지, 공시 빈도 |
| 정책 risk | 지주사 규제 변동 (공정거래법, 금산분리) | 규제 발표 더미 변수, event study |

### 3-1. 시계열 변동 요인 (단기 변동)
- **포트폴리오사 업황** — SK 하이닉스 호황기엔 NAV 자체가 커지지만 할인율도 커지는 경향 (자회사 가치를 시장이 충분히 반영 못 함)
- **거시경제** — 환율, 금리, KOSPI 흐름
- **이벤트** — 자사주 소각, 인적분할, 배당 발표, ESG 등급 변동, 정책 발표
- **외국인 수급** — 외국인 지분율 변화

## 4. 분석 시 주의해야 할 함정

### 4-1. 동시성 (Simultaneity)
NAV 할인율은 **시가총액과 자회사 시가총액의 비율**. 두 가격이 동시에 움직이므로 회귀에서 인과를 단순히 못 봄.
- 권고: lag 변수 사용, event study, 또는 differences-in-differences 필요 시

### 4-2. 비정상성 (Non-stationarity)
KOSPI, 환율 시계열은 비정상. 차분 또는 변화율 사용. 단위근 검정(ADF) 필수.

### 4-3. 다중 비교 (Multiple Testing)
50 개 팩터를 동시에 테스트하면 5% 유의수준에서 우연히 2~3 개 유의. **본 시스템은 50+ 가설을 병렬 테스트하므로 Bonferroni 또는 FDR 보정이 필수**. Verifier 가 강제.

### 4-4. 데이터 갱신 주기 차이
- 일별: 주가, 환율, 금리
- 분기별: 재무제표, 지분 공시
- 연 1회: KCGS 등급, ESG 등급
- 비정기: 뉴스, 공시 (event)

분기 변수와 일별 변수를 혼합할 때는 **일별 변수를 분기 평균화** 또는 **분기 변수를 forward-fill** — 일관된 정책을 가설 단위로 명시.

### 4-5. 생존편향
한국 지주사 모집단을 시기마다 새로 정의해야 함. 사라진 회사를 빼면 평균 할인율이 과소 추정됨.

### 4-6. 정의의 미묘함
- "NAV 할인율" 의 분모를 NAV 로 할 것인가 시가총액으로 할 것인가? 통상 NAV 분모.
- 비상장 가치 추정 변경 시 할인율 자체가 변함 — analyst-by-analyst 차이.
- 본 시스템은 **자체 NAV 추정** + **공개 NAV 추정(NH투자, 미래에셋 등 리포트)** 두 트랙으로 비교 가능 시 비교.

## 5. 본 시스템의 분석 단위

| 단위 | 빈도 | 비고 |
|---|---|---|
| 일별 시계열 | 일 | 가격, 거래량, 환율, 금리 |
| 분기 패널 | 분기 | 재무제표, 지분 변동 |
| 이벤트 | 비정기 | 자사주 소각, 배당, 인적분할 발표일 |
| 단면 비교 | 시점별 | 한국 vs 글로벌 지주사 |

각 가설은 어느 단위에서 테스트되는지 `time_range` + `data_sources` 에 명시.

## 6. 산출물의 의미

본 시스템은 **"SK NAV 할인율을 어떻게 줄일 것인가"** 의 직접 답이 아니라, **"어떤 변수가 할인율과 통계적으로 유의한 관계가 있는가, 그 효과 크기는 얼마인가"** 를 발굴합니다.

해석은 사람(SK PR/IR)이 합니다. 본 시스템의 산출물은:
1. 검증된 finding 목록 (variable, effect size, significance, robustness)
2. 그 finding 의 provenance (어떤 가설→어떤 데이터→어떤 분석→어떤 판정)
3. 각 finding 의 한계와 가정

> 핵심 원칙: **거짓 양성(False positive) 보다 거짓 음성(False negative) 이 차라리 안전**. Verifier 는 보수적으로 판정.
