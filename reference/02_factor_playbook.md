# 02. 팩터 플레이북 — 카테고리별 후보 변수 카탈로그

> Hypothesis 가 새 가설을 만들 때 1차로 참조하는 카탈로그. 여기 없는 카테고리·변수도 만들 수 있지만, **이 카탈로그에 있는 변수부터 우선 소진**한 뒤 새 영역으로 확장합니다.
> 각 변수마다 "측정 방법" + "예상 데이터 소스" + "주의" 를 명시. Collector 는 데이터 소스 행을 보고 수집 절차로 매핑.

---

## 카테고리 균형 원칙

본 시스템은 6 개 카테고리에 걸쳐 균형 있게 가설을 발굴합니다. 한 카테고리에 가설이 5 개 이상 쌓이면, Hypothesis 는 **다른 카테고리로 자기 회피** 합니다.

| 카테고리 | 비중 가이드 | 변수 풀 |
|---|---|---|
| `governance` | 25% | 거버넌스·이사회·소액주주 |
| `portfolio` | 25% | 자회사 업황·구성 |
| `macro` | 15% | 거시경제·외부 환경 |
| `internal` | 15% | 자사주·배당·내부 활동 |
| `esg` | 10% | ESG·지속가능성 |
| `brand_pr` | 10% | 브랜드·PR·정보 비대칭 |

## 우선순위 결정 가이드 (Hypothesis 가 priority 결정 시)

```
high   ← 데이터 즉시 확보 + 학술/실무 근거 + 이전 분석에서 단서
medium ← 위 3 중 2 개
low    ← 데이터 접근 어려움 OR 인과 약함 OR 이전에 비슷한 가설 다수 reject
```

### "확보 가능한 데이터" 의 의미
- ✅ DART, pykrx, ECOS, KIND — 즉시 가능
- 🟡 KCGS 보고서 (PDF 다운로드 후 표 추출 필요)
- 🟡 빅카인즈 (회원가입 후 검색)
- 🔴 MSCI ESG 상세 — 유료, 회피
- 🔴 FnGuide 컨센서스 일별 — 보통 유료

## 가설 작성 예시 (good vs bad)

### 좋은 가설 (high priority)
```
H-260427-001
factor_name: foreign_holding_pct (외국인 지분율)
category: governance
causal_claim: 외국인 지분율 1%p 증가 시 NAV 할인율 0.1~0.3%p 감소.
              메커니즘: 외국인이 거버넌스 개선 기대를 가격에 반영.
data_sources:
  - {source: "pykrx", fetch: "stock.get_market_cap_by_date"}
  - {source: "pykrx", fetch: "stock.get_exhaustion_rates_of_foreign_investment_by_date"}
time_range: 2018-01-01..2026-04-01
priority: high
rationale: 권재민 (2019), 김지윤 (2021) 선행연구. 한국 지주사 패널에서 음의 상관 보고.
           SK 일별 데이터 확보 즉시 가능.
depth: 0
```

### 나쁜 가설 (만들지 말 것)
- "시장 심리가 영향" — 측정 불가
- "ESG 가 좋으면 좋다" — 변수 미명시
- "정책이 좋으면 NAV 늘어남" — 메커니즘·측정 불명확
- 같은 factor_name + 같은 데이터 소스의 가설을 5번 이상 시도

## 카테고리 외 영역 — Hypothesis 가 자기 회피 후 탐색할 곳
- 비교 단면: 글로벌 지주사 vs 한국 지주사 단면 회귀
- 이벤트 + 시계열 결합: 자사주 소각 발표 후 60일 누적 초과 수익률
- 비선형: 거버넌스 등급 변동의 비대칭 효과 (악화 vs 개선)
- 상호작용: 외국인 지분율 × 매크로 환경 (위험회피 시기에 효과 ↑?)
